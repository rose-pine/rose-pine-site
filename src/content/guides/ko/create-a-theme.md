Rosé Pine 멤버들은 커뮤니티 테마를 위해 절제된 팔레트를 창의적이고 다양하게 해석하는 것을 언제나 장려합니다. 만약 가이드와 함께 보다 체계적인 방식을 선호하신다면, 팀이 도움을 드릴 수 있는 Rosé Pine GitHub 조직의 공식 테마로 등록하는 것도 환영합니다.

새로운 테마의 베이스로 사용할 [저장소 템플릿](https://github.com/rose-pine/rose-pine-template)으로 시작해보세요.

```sh
gh repo create my-app --public --clone --template rose-pine/rose-pine-template
```

빌드 도구인 [bloom](https://github.com/rose-pine/rose-pine-bloom)을 사용하면 팔레트에 쉽게 접근하고 세 가지 변형을 모두 포함할 수 있습니다. `bloom init <filename>` 명령을 통해 기존 테마 파일로부터 템플릿을 생성하세요.

빌드가 완료되면 공식 테마 또는 커뮤니티 테마로 [테마를 제출](/new)할 수 있습니다. 공식 테마의 경우 저장소를 이전할 수 있도록 GitHub 조직에 초대해 드립니다. 이전된 테마는 웹사이트에 자동으로 추가됩니다. 커뮤니티 테마의 경우 양식을 제출해 주시면 사이트에 추가해 드립니다. 추가적인 작업은 필요하지 않습니다.

커뮤니티와 함께 나누어 주셔서 감사합니다. 여러분이 만들어낼 멋진 테마를 기대하고 있겠습니다!
